# Product

## Register

product

## Users

People use Magnet or another window arranger to position existing application and browser windows across monitors and macOS Spaces. After displays have been off, macOS sometimes changes window geometry, monitor, and Space assignment. Browser tabs and logged-in sessions are already open.

## Product Purpose

Remember named window arrangements and restore the same existing windows with one explicit action. The user confirmed that recovering Space assignments is essential. No movement happens on launch, wake, display changes, or Space changes. Success means recovering the user's working arrangement without rebuilding it manually.

## Brand Personality

Minimal, native, practical. A small macOS utility whose interface serves the two actions requested by the user: Remember and Restore.

## Anti-references

Competing tiling tools, dashboards, account flows, automatic snapping, and global keyboard shortcuts. Magnet remains the user's manual window arranger.

## Design Principles

- Keep Remember and Restore easy to find in the menu bar.
- Require unique window matches and report skipped or adjusted windows.
- Preserve saved monitor and Space destinations during temporary fallback.
- Use native macOS menus, system typography, and permission guidance.
- Keep layout management limited to naming, renaming, overwriting, and deleting local layouts.

## Accessibility & Inclusion

Use standard AppKit controls and system appearance. Provide text labels and clear Accessibility permission instructions. Permission denial must leave windows untouched and the app usable.
