# Design

Native macOS menu-bar utility using NSStatusItem and NSMenu, standard AppKit controls, system fonts and semantic system colors. Follow the user's system appearance. No custom theme, decorative animation, dashboard, or keyboard shortcuts.

The user is returning to a two-monitor workspace and wants to recover its arrangement quickly. The primary commands are Remember Layout and Restore. Each named layout provides Restore, Overwrite, Rename, and Delete. A text report explains partial restoration, unsupported windows, and missing destinations. Setup explains Accessibility permission and the limited private API requirement for Spaces.
